# Free tools by Zelda Rose

Free, private, offline tools. Everything runs in your browser. Each tool is one self-contained HTML file with a strict Content-Security-Policy (no network requests, no cookies, no analytics). View source to read the whole thing.

- `index.html`: hub
- `scam-checker.html`: general scam red-flag checker
- `crypto-scam-checker.html`: crypto scam checker (drainers, fake airdrops, seed-phrase theft, fake support, pig butchering, recovery scams, honeypot tokens, lookalike domains)
- `xrpl-safety-check.html`: XRP Ledger address/destination-tag validator (base58check, X-address decoding, address-poisoning compare) and transaction explainer (flags SetRegularKey, SignerListSet, disable-master-key, AccountDelete, zero-price NFT offers, partial payments)
- `review-reply-helper.html`, `tenant-letter-kit.html`, `benefits-finder.html`
